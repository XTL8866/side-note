# 侧边便签 SideNote

贴在桌面边缘的待办提醒小工具。平时只露出一叠彩色标签，鼠标停留 0.4 秒才滑出清单。

## 下载

从 [Releases](../../releases) 下载 `SideNote-win32-x64.zip`，解压后双击 `SideNote.exe`，免安装。

未做代码签名，首次运行时 Windows SmartScreen 会提示"未知发布者"，点"更多信息 → 仍要运行"即可。

## 怎么用

- **悬停展开**：鼠标在彩色标签上停约 0.4 秒，清单才会滑出来（快速划过不会误触）
- **移开自动收起**：0.13 秒内收回，鼠标甩得再快也会收起，不会卡在展开状态
- **点标签**：直接切到那个清单
- **底部输入框**：`明天下午3点 交周报` 然后回车，自动识别时间和标题
- **⚙ 齿轮**：设置停靠位置、大小、悬停延迟，以及增删改标签（名称和颜色都能改）
- **⠿ 拖动把手**：按住可以把整条拖到屏幕任意位置，靠边 30px 自动吸附
- **📌 图钉**：固定展开，不自动收起。钉住时切到别的程序也不会收；再点一下或按 Esc 取消
- **Esc**：取消固定并收起

## 全屏时让位

看视频、开会演示、玩游戏的时候，便签哪怕只露出一条标签也是干扰。所以：

- 只要**有别的窗口占了整块屏幕**，便签就自动收起来，完全不露
- 那个窗口退出全屏，便签自己回来（还是收起的，鼠标不上去不会展开）
- 全屏期间到点的提醒先记着，退出全屏再一起弹，不会盖在画面上
- 你手动从托盘隐藏的话，退出全屏不会自己冒出来 —— 那是你主动藏的
- 设置里可以关掉（默认开），托盘菜单也能切换

判断方式：每 0.5 秒看一次前台窗口，如果它正好铺满整块显示器就算全屏。
桌面、开始菜单、输入法这类系统界面不算。

## 被窗口挡住时让位

比全屏更常见的情况：浏览器最大化、编辑器开着，便签还浮在最上面，正好压住别人一行字。所以：

- **有窗口压住便签那一块**（不是全屏也算），便签整个收起来，一个像素都不留
- 想看的时候，把鼠标甩到**便签原来贴的那条屏幕边缘**、停一下（约 0.2 秒），它就滑出来；移开又躲回去
- 压着它的窗口挪开或关掉，便签自动回来（仍是收起态）
- 钉住（📌）期间不受影响，一直看得见
- 按 `Ctrl+Alt+N` 会强制把它叫出来并留 20 秒，够把字打完
- 设置里「被挡住时让位」可以单独关掉（默认开），托盘菜单也能切换

判断方式：按窗口 Z 序从上往下扫，第一个「不是自己、不是系统外壳」并且压住便签区域的窗口，
就算遮挡（压住 30% 以上才触发）。这一项和全屏判断共用同一个检测进程。

## 到点提醒

- 输入时写了时间（`明天下午3点`、`周三 9:30`、`10-25`、`今晚8点`），到点会自动提醒
- 到点时**便签会自己从屏幕边缘滑出来**，卡片上直接点「10 分钟后 / 明天再说 / 完成」
- 之后 15 秒内不会因为鼠标移开就立刻收回，免得没看清就没了
- 列表里已经过期的任务，时间标签会变红
- 每条只提醒一次；程序没开的时候错过的，下次打开会补提醒（超过 12 小时的静默跳过，不刷屏）
- 设置里的「到点提醒」可以整体关掉，「试一下」可以立刻看效果

只写日期不写时间（比如「今天」）不会到点弹提醒，因为不知道几点。
提醒用的是便签自己滑出来，不是系统通知 —— 免安装的 exe 没注册开始菜单快捷方式，
Windows 桌面通知经常不弹，这样更靠得住。

## 托盘菜单（右下角小图标）

- 显示 / 隐藏
- 置顶显示（勾选后永远压在其他窗口上方）
- 全屏时让位（有窗口全屏就自动躲起来）
- 被窗口挡住时让位（有窗口压住它就收起来）
- 开机自启
- 退出

## 全局快捷键

`Ctrl + Alt + N`：直接唤出输入框，适合随手记一条。

## 项目结构

```
main.js                   主进程：窗口、托盘、全屏 / 遮挡检测、提醒调度
preload.js                预加载脚本：向渲染层暴露受限的 native API
src/index.html            桌面版界面（构建产物，勿直接编辑）
prototype/index.html      网页原型，UI 的唯一真源
tools/build-renderer.js   把原型注入应用层，生成 src/index.html
tools/make-icon.js        纯 Node 生成 64×64 图标（PNG + ICO）
assets/                   图标与 PowerShell 窗口检测脚本
```

改界面请改 `prototype/index.html`，再执行 `npm run build`，**不要**直接编辑 `src/index.html`。

## 数据存在哪

保存在本机 `%APPDATA%\side-note\Local Storage` 里，不上传任何服务器。
删除这个目录即可彻底清空。

## 开发

```bash
npm start                 # 本地运行
node tools/make-icon.js   # 重新生成图标
node tools/build-renderer.js   # 把 prototype/index.html 注入成 src/index.html
npm run pack              # 打包到 dist/
```

原型（网页版）在 `prototype/index.html`，桌面版由 `tools/build-renderer.js` 在原型末尾
注入「应用层」生成，两者共用一个源。

## 已知限制

- 未做代码签名，首次运行时 Windows SmartScreen 可能提示"未知发布者"，点"更多信息 → 仍要运行"即可
- 全屏 / 遮挡判断靠一个常驻的 PowerShell 小进程（本机自带，不用装东西），所以任务管理器里会多一个
  `powershell.exe`，内存 50MB 左右。如果它起不来（被安全软件拦），程序会正常跑，只是这两个功能失效
- 判断每 0.5 秒一次，所以窗口变化后便签最多晚半秒让位
- 被挡住时只要求「鼠标贴到屏幕边缘停一下」，不追求「完全不用动手」——所以要拿它写字时得先贴一下边
